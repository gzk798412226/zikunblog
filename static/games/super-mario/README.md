# 超级马里奥 HTML5 游戏 🎮

一个使用 HTML5 Canvas 和 JavaScript 构建的经典超级马里奥兄弟风格平台游戏。

![Super Mario HTML5](https://img.shields.io/badge/Game-Super%20Mario%20HTML5-red)
![HTML5](https://img.shields.io/badge/HTML5-Canvas-orange)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)
![CSS3](https://img.shields.io/badge/CSS3-Responsive-blue)

## 🎯 游戏特色

- **经典马里奥游戏玩法**，具有像素级精确的碰撞检测
- **多个关卡**，难度逐渐递增
- **动画精灵**，包括马里奥和敌人（板栗仔）
- **粒子特效**，收集金币和击败敌人时的特效
- **响应式设计**，支持桌面端和移动端
- **本地高分记录**

## 🎮 游戏玩法

### 控制方式
- **← → 方向键** 或 **A/D 键**: 左右移动
- **空格键**、**↑ 方向键** 或 **W 键**: 跳跃
- **回车键**: 开始/暂停游戏
- **P 键**: 暂停/继续
- **R 键**: 重置游戏

### 游戏目标
- 收集所有**金币**来完成每个关卡
- 跳到**敌人（板栗仔）**头上击败它们
- 避免从侧面接触敌人
- 完成关卡以增加分数

### 计分系统
- 🪙 **收集金币**: 100 分
- 👾 **击败敌人**: 200 分
- 🏆 **完成关卡**: 500 分

## 🚀 开始游戏

1. **克隆仓库**
   ```bash
   git clone https://github.com/lifejolly/super-mario-html5-game.git
   cd super-mario-html5-game
   ```

2. **打开游戏**
   - 直接在浏览器中打开 `index.html` 文件
   - 或使用本地服务器运行：
   ```bash
   # 使用 Python
   python -m http.server 8000
   
   # 使用 Node.js (http-server)
   npx http-server
   ```

3. **开始游玩！**
   - 点击"开始游戏"按钮或按 'S' 键
   - 使用方向键或 WASD 控制马里奥
   - 尽情享受游戏乐趣！ 🎉

## 🛠️ 技术特性

- **面向对象设计**: 清晰的游戏实体分离
- **Canvas 渲染**: 流畅的 60fps 游戏体验
- **物理引擎**: 自定义重力和碰撞系统
- **状态管理**: 游戏状态（运行、暂停、游戏结束）
- **关卡系统**: 渐进式难度调整
- **动画系统**: 基于帧的精灵动画

## 🎨 游戏机制

### 玩家机制
- **移动**: 平滑的加速度和摩擦力
- **跳跃**: 基于输入的可变跳跃高度
- **碰撞**: 具有适当边缘检测的平台碰撞
- **生命系统**: 3 条生命，带有重生机制

### 敌人 AI
- **巡逻行为**: 敌人在指定区域内巡逻
- **平台感知**: 敌人在平台边缘转向
- **碰撞响应**: 根据碰撞角度产生不同结果

### 关卡设计
- **渐进难度**: 每个关卡引入新挑战
- **多种平台**: 各种平台布局
- **战略性金币放置**: 鼓励探索和冒险
